# Python Drone Move Challenge

هذه النسخة تعتمد على **نفس أسلوب برنامج Python الأصلي**:

- الطالب يتحكم بالدرون مباشرة.
- `SPACE` للإقلاع / الهبوط.
- `↑` للتقدم.
- `← →` للدوران.
- `R` لإعادة المستوى.
- الهدف هو الوصول إلى منصة الهدف بأقل عدد من **حركات التقدم**.

## الفرق عن النسخة السابقة

لا توجد بلوكات Drag & Drop ولا بناء برنامج طويل.

اللعبة الآن تركز على:

**كم حركة تحتاج للوصول إلى الهدف؟**

وتحتوي على:

- 12 مستوى.
- عوائق ومسارات مختلفة.
- أفضل مسار لكل مستوى محسوب تلقائياً.
- 3 نجوم إذا وصلت بأفضل عدد حركات.
- نجمتان إذا كنت قريباً من الأفضل.
- نجمة إذا أكملت المهمة بعدد حركات أكبر.
- عداد محاولات.
- مؤقت.
- بطارية.
- آخر أمر Python يظهر أسفل المحاكي.

## احتساب الحركات

مثل البرنامج الأصلي:
- التقدم = حركة واحدة.
- الدوران لا يزيد عداد الحركات.
- الإقلاع والهبوط لا يزيدان العداد.
