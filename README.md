# Python Drone Rescue — Arrow Key Edition

هذه النسخة لا تحتوي على Drag & Drop إطلاقاً.

## التحكم
- SPACE = إقلاع / هبوط
- ↑ = تقدم 50
- ← = دوران يسار 90°
- → = دوران يمين 90°
- R = إعادة المستوى
- H = مساعدة

## احتساب Moves
مطابق لفكرة برنامج Python الأصلي:
- التقدم الناجح فقط يزيد `Moves`.
- الدوران لا يزيد العداد.
- الإقلاع والهبوط لا يزيدان العداد.
- الاصطدام/الحركة المحجوبة لا تزيد العداد.
